# 🧠 DevMentor AI

## 📌 Descrição do Projeto

O **DevMentor AI** é um aplicativo Android que integra videoconferência com inteligência artificial para auxiliar desenvolvedores em sessões de mentoria técnica.

O app permite que usuários criem ou entrem em salas de reunião e, durante a chamada, utilizem um chat inteligente para receber sugestões automáticas, explicações de código e suporte em tempo real.

---

## 🚀 Proposta de Valor

Diferente de aplicativos tradicionais de videoconferência, o DevMentor AI oferece:

* 💬 Chat inteligente com sugestões automáticas
* 🧠 Assistência com IA para código
* 🎥 Comunicação em tempo real com vídeo
* 📈 Melhor aprendizado e produtividade para desenvolvedores

---

## 🛠 Tecnologias Utilizadas

* Kotlin (Android)
* Jitsi Meet SDK
* Manus AI
* Android Studio

---

## 📲 Funcionalidades

* Criar ou entrar em salas de videoconferência
* Comunicação por vídeo e áudio em tempo real
* Chat integrado
* Sugestões automáticas (IA - modo demonstrativo)

---

## ⚙️ Instalação

1. Clone o repositório:
   git clone https://github.com/seu-usuario/devmentor-ai

2. Abra o projeto no Android Studio

3. Aguarde a sincronização do Gradle

4. Execute o app em um emulador ou dispositivo físico

---

## ▶️ Como Usar

1. Abra o aplicativo
2. Digite o nome da sala
3. Clique em **Entrar na Call**
4. Utilize a videoconferência normalmente
5. Use o chat para interagir e testar sugestões da IA
